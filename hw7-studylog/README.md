# HW7 - Study-Log Helper

A tiny bash script to practice everything from the Advanced Bash lecture.

## What you'll build
A script `studylog.sh` that logs a timestamped study session for you and
reports how many sessions you've logged so far.

## How to run it (from VS Code's integrated terminal)
```bash
chmod +x studylog.sh     # make it executable (one time)
./studylog.sh Boiler     # run it, passing your name
```

Expected output on the first run:
```
Thanks Boiler! You have logged 1 study session(s).
```
Run it a few more times and watch the count go up. Open `study_log.txt`
to see your entries.

## Where to look for help
Open `studylog.sh` - every TODO points to the exact lecture slide that
shows the syntax you need. If you're still stuck, post on Ed Discussion
(show what you've tried!).
